# Knowledge stubs

Facts that cannot be code, tests or fixtures. Each file is a draft of a scoped Devin knowledge note for the
customer Devin org. Every value marked `TBD` is unknown to the authors of this scaffold and must be filled by
the named owner before the note is published; do not guess.

If something here could become a lint check, a rule, or a fixture, move it there and delete it from here.

| file | scope (trigger) | owner |
|---|---|---|
| `quadient-designer.md` | when generating or validating Quadient artifacts, or triaging Designer errors | partner Quadient designer |
| `customer-clearance-boundaries.md` | when handling customer artifacts, fixtures, or anything that could leave the customer environment | partner lead / customer security |
| `customer-naming-and-revisions.md` | when naming target objects, variables, or reading form revision markers | customer forms team |
